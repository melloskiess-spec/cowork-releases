# Cowork для Windows

Сборки приложения Cowork: живая панель совместной работы двух пользователей Claude Code, с уведомлениями и автообновлением.

**Скачать:** раздел [Releases](../../releases/latest) → `Cowork-Setup-<версия>.exe`. Windows предупредит о неизвестном издателе (сборка не подписана): «Подробнее» → «Выполнить в любом случае».

Здесь только код приложения и панели, без настроек вашего проекта. Новая версия выходит, когда в репозиторий пушится тег `vX.Y.Z` (версия в `app/package.json` должна совпадать). GitHub Actions соберёт установщик и опубликует релиз, а установленные приложения обновятся сами.

Дизайн панели: шаблон Onda от 8B (MIT), см. `dashboard/ONDA-LICENSE` и `dashboard/CREDITS.md`.
