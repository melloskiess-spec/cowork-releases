# Cowork: код приложения

Этот репозиторий публичный. Здесь код самого Cowork, его меняют прямо из приложения на вкладке «✦ Cowork».

## Что где
- `dashboard/index.html` — весь интерфейс: один файл, HTML, CSS и JS без сборки. Почти все правки внешнего вида и поведения здесь.
- `app/main.js` — Electron: окно, трей, автообновление, запуск Claude Code (`claude -p --output-format stream-json`).
- `app/preload.js` — мост `window.coworkNative` между интерфейсом и `main.js`.
- `app/package.json` — версия приложения и настройки сборки (electron-builder, NSIS).
- `.github/workflows/release.yml` — сборка .exe и релиз на GitHub.

## Как проверить правку
- Кнопка «Предпросмотр» в приложении открывает `dashboard/index.html` из этой папки, без сборки. Вернуться: «Вернуть обычный вид» или меню в трее.
- Перед выпуском: `node --check app/main.js` и `node --check app/preload.js`. JS в `dashboard/index.html` должен разбираться без ошибок.

## Как выпустить обновление
1. Поднять версию в `app/package.json` (обычно patch: 0.4.0 → 0.4.1).
2. Закоммитить и запушить в `main`.
3. GitHub Actions сам соберёт установщик и выпустит релиз `v<версия>`. Приложения у обоих обновятся в течение получаса или по кнопке «Обновить».

Если версия в `app/package.json` не менялась, релиз не создаётся.

## Правила
- Репозиторий публичный: никогда не коммить имена каналов (`COWORK_TOPIC`), токены, пароли, личные данные.
- Сохраняй визуальный язык: цвета из `:root` (`--c1` … `--c8`), шрифты Gabarito и Onest, фиолетовые точки, кнопки-таблетки.
- Не ломай формат событий в канале (`{v, user, event, chat, run, text, ...}`): у напарника может быть старая версия, пока он не обновится.
- Режим «Оба Claude»: ведущий пишет в ответе блок ```cowork-delegate```, приложение шлёт событие `delegate` (`to` = напарник), у напарника его Claude работает в своей копии репозитория и отвечает событием `report` (из блока ```cowork-report```). Подтверждение: событие `take` с `ask` = cid.
- Панель «Просмотр» справа: артефакты (HTML из `.cowork/artifacts`, событие `artifact` с `n`, `file`, `u`), сайты и запущенное приложение (`proj.runCmd`, IPC `app:start`/`app:stop`). Браузер для Claude — Playwright MCP (`--mcp-config`), снимки из `.cowork/shots` уходят событием `shot` с `img`.
- Общий просмотр: событие `view` (`url` или `art`; для localhost ещё `shot` — снимок панели раз в 15 с), напарник открывает то же у себя. 21st.dev: событие `here` несёт `t21`, и Claude без 21st поручает поиск компонентов через ```cowork-delegate``` тому, у кого 21st подключён.
